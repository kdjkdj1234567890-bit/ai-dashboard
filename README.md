# 📊 AI 자동 인사이트 대시보드

> 💼 **외주 문의 환영** — 위시켓·크몽에서 "김동진"으로 검색하세요. 작동하는 데모로 먼저 보여드립니다.

CSV·엑셀 데이터를 업로드하면 AI가 **7종의 인사이트를 자동으로 뽑아 차트와 함께 보여주는** 대시보드입니다.
외부 AI API 없이 로컬에서 완전히 동작합니다.

**이런 분께 필요합니다**: 매출·마케팅 데이터를 보지만 "그래서 뭘 해야 하지?"가 궁금한 대표님, 엑셀 정리에 시간을 쏟는 실무자

---

> **이 프로젝트는 시연용 프로토타입입니다.**
> 핵심 플로우(CSV 업로드 → 컬럼 자동 인식 → 차트 자동 생성 → 인사이트 자동 서술)가
> 실제로 동작하는 것을 보여주기 위한 데모이며, 정식 구축 시에는
> LLM 연동(자연어 질의·서술 고도화)과 실시간 DB 연동을 전제로 합니다.

"AI가 데이터를 읽고 인사이트를 말해주는" 대시보드 데모.
외부 AI API 없이 **로컬에서 완전히 동작**하는 룰 기반 자동 분석 엔진이 포함되어 있습니다.

## 실행 방법

```bash
cd 03-ai-dashboard
bash run.sh
# 브라우저에서 http://127.0.0.1:5000 접속
```

필요 패키지(Flask, pandas, numpy)가 없으면 `run.sh`가 자동 설치합니다.
인터넷 연결 없이도 동작합니다 (Chart.js는 `static/vendor/`에 로컬 번들).

## 5분 시연 시나리오

| 시간 | 내용 |
|------|------|
| 0:00–0:40 | 첫 화면: "CSV를 올리면, AI가 읽고 말해줍니다". 파일이 없어도 **샘플 데이터로 바로 시연** 가능함을 안내 |
| 0:40–1:30 | **① CSV 업로드** — `sample_data/monthly_sales_2025.csv`(가상 월별 매출 12개월, 72행)를 올리거나 "샘플 데이터로 대시보드 보기" 클릭. 로딩 인디케이터 표시 |
| 1:30–2:20 | **② 컬럼 자동 인식** — 상단 태그에서 `월→날짜`, `매출액(만원)→숫자`, `제품군/채널→범주`로 자동 분류된 것을 확인. KPI 카드 4종(총합·평균·전월 대비·최고월) 설명 |
| 2:20–3:30 | **③ AI 인사이트** — 헤드라인("2025년 12월 매출액, 전월 대비 27.5% 감소") + 6종 카드. 핵심 포인트: **이상치 탐지 카드**가 2025년 11월(Z-score 2.65)을 짚어내고, "평균 대비 32% 높음. 원인 파악 필요"라고 말하는 것을 시연 — 12월 감소는 11월 스파이크(블랙프라이데이) 이후 정상화임을 차트와 함께 설명 |
| 3:30–4:30 | **④ 자동 생성 차트** — 시계열 추이(11월 스파이크 가시화), 제품군/채널별 막대, 비중 파이, 분포 히스토그램 7종이 데이터 구조에 맞춰 자동 구성된 것을 확인 |
| 4:30–5:00 | **⑤ 신뢰 포인트** — "모든 수치는 업로드된 데이터에서 직접 계산되며, 외부 전송이 없습니다" + 엣지 케이스 시연(날짜 없는 CSV → 안내 메시지, 숫자 없는 CSV → 친절한 오류). 정식 구축 로드맵(아래) 언급으로 마무리 |

## 자동 생성 인사이트 7종 (전부 룰 기반, 외부 API 없음)

1. **전월/전주 대비 증감률** — 마지막 기간 vs 직전 기간, 수치 포함 서술
2. **추세 분석** — 회귀 기울기로 상승/하락/횡보 판정
3. **이상치 탐지** — Z-score ≥ 2.0 기간 감지 후 알림
4. **상위/하위 항목 요약** — 범주별 합계 기준 1·2위와 최하위, 비중 포함
5. **그룹 비교** — 두 번째 범주(예: 채널) 최대/최소 배율
6. **분포 분석** — 왜도(skewness) 기반 치우침 서술
7. **상관 분석** — 광고비 등 두 번째 숫자 컬럼과 상관계수

## 기술 스택

- **Backend**: Python 3.12, Flask 3, pandas, numpy
- **Frontend**: Jinja2 템플릿, Chart.js 4 (로컬 번들 — CDN 의존 없음), 순수 CSS (다크 대시보드 테마, 반응형)
- **분석 엔진**: `insights.py` — 컬럼 타입 자동 인식(날짜/숫자/범주), KPI·차트 스펙·인사이트 생성
- **테스트**: `tests/test_e2e.py` — 19개 테스트. 인사이트 수치는 pandas 독립 재계산 값과 대조 검증

## 엣지 케이스 처리

| 입력 | 동작 |
|------|------|
| 빈 파일 / 파일 미선택 | 안내 메시지, 분석 중단 |
| `.csv` 아닌 확장자 | "CSV 파일만 업로드" 안내 |
| 숫자 컬럼 없음 | "숫자형 컬럼을 찾지 못했습니다" 안내 |
| 날짜 컬럼 없음 | 시계열 차트 대신 안내 배너, 나머지 정상 렌더링 |
| 깨진 CSV / 10MB 초과 | 친절한 오류 메시지 (traceback 미노출) |
| CP949 인코딩 | 자동 인식 |

## 정식 구축 시 확장 방안

1. **LLM 연동** — 룰 기반 서술 → LLM 자연어 생성으로 교체. "왜 11월에 스파이크가 났지?" 같은 후속 질의응답(챗봇) 추가
2. **실시간 DB 연동** — CSV 업로드를 넘어 PostgreSQL/BigQuery 커넥터, 스케줄 새로고침
3. **인증·권한** — 사내 SSO, 대시보드별 접근 제어, 감사 로그
4. **고급 분석** — 시계열 예측(Prophet/ARIMA), 코호트·퍼널 분석, 알림(슬랙/메일) 연동
5. **배포** — Docker 이미지, Gunicorn + Nginx, HTTPS
